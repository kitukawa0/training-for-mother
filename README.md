# 🌿 Календарь домашних тренировок

Лёгкое веб-приложение для ежедневных 8–15-минутных домашних тренировок.
Чистый HTML/CSS/JS, без фреймворков и без сервера — работает прямо
в браузере и готово к публикации на GitHub Pages.

## Как опубликовать на GitHub Pages

1. Создайте новый репозиторий на GitHub и загрузите в него все файлы этой папки.
2. В репозитории откройте **Settings → Pages**.
3. В разделе **Source** выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через минуту-две сайт появится по адресу вида
   `https://ваш-логин.github.io/название-репозитория/`.

Можно также просто открыть `index.html` двойным щелчком — приложение
работает полностью локально, без интернета (кроме шрифтов Google Fonts,
которые подключены необязательным образом — без интернета приложение
просто покажет системный шрифт).

## Структура проекта

| Файл | Назначение |
|---|---|
| `index.html` | разметка трёх экранов приложения |
| `style.css` | все стили, включая CSS-анимации иллюстраций упражнений |
| `utils.js` | даты, форматирование, детерминированный генератор случайных чисел |
| `storage.js` | вся работа с `localStorage`: прогресс, серия дней, статистика |
| `exercises.js` | база из 56 упражнений и генератор тренировки на день |
| `calendar.js` | построение и отрисовка календаря месяца |
| `timer.js` | круговой таймер обратного отсчёта |
| `figure.js` | иллюстрация упражнения (см. ниже) |
| `script.js` | управление экранами, воспроизведение тренировки, конфетти, звук |

## Про иллюстрации упражнений

В задании было пожелание использовать готовые GIF из интернета. На практике
подключение чужих GIF по прямой ссылке — самое ненадёжное место такого
приложения: ссылки со временем перестают открываться, часть хостингов
блокирует показ картинок на сторонних сайтах, а часть просто медленно
грузится или показывает рекламу рядом. Для приложения, которым будет
пользоваться мама каждый день, это означало бы, что через какое-то время
карточки упражнений могут начать показывать «битую» картинку.

Поэтому по умолчанию каждая карточка упражнения показывает лёгкую
собственную CSS-анимацию (стилизованная фигурка, которая шагает, крутит
руками, поворачивает корпус и т. д. — в зависимости от категории
упражнения). Она гарантированно работает офлайн и на GitHub Pages, ничего
не «отваливается».

Если всё же захотите подключить настоящие GIF — это не потребует
переписывать код: у каждого упражнения в `exercises.js` есть поле
`gifUrl: ''`. Впишите туда прямую ссылку на GIF (заканчивается на `.gif`)
— и карточка автоматически покажет именно её вместо встроенной анимации.

## Про логику блокировки дней

Открыть можно только сегодняшний день, и только если он ещё не выполнен.
Все будущие дни всегда закрыты на замок. Прошедшие дни — это уже история:
зелёный, если тренировка была сделана, приглушённый, если день был
пропущен. Если пропустить день, серия (🔥) обнулится, но это не помешает
начать заниматься на следующий день заново — старые дни просто нельзя
редактировать задним числом.

## Полезно знать

- Прогресс, серия дней и статистика хранятся в `localStorage` браузера —
  они не пропадут при обновлении страницы, но привязаны к конкретному
  браузеру и устройству.
- Тренировка на каждый день генерируется автоматически и одинакова при
  повторном открытии того же дня (специально, чтобы не «перегенерировать»
  тренировку, если случайно обновить страницу посреди занятия).
- Есть кнопка 🔊/🔈 в шапке — выключает мягкие звуковые сигналы.
